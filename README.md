# 🚚 Интеграция маркетплейса «MarketHub» со службой доставки «FastDelivery»

## 📋 Бизнес-контекст

**MarketHub** — rapidly growing маркетплейс с 15 000 заказов в день. На данный момент доставка осуществляется только собственными курьерами в 5 городах присутствия. Бизнес принял решение подключить внешнюю логистическую службу **FastDelivery**, чтобы:

- Выйти в **50+ городов** без найма собственных курьеров
- Снизить стоимость последней мили на **25%** за счёт консолидации отправлений
- Дать покупателям **онлайн-трекинг** (сейчас tracking отсутствует)
- Автоматизировать **финансовые сверки** (сейчас ручной обмен CSV)

## 👤 Моя роль

**Системный аналитик** на проекте интеграции. Полный цикл:
- Сбор требований у 6 стейкхолдеров (CPO, CTO, логистика, финансы, внешний техлид, DBA)
- Описание Use Cases и BPMN бизнес-процессов
- Проектирование API-контракта (OpenAPI 3.0)
- Согласование нефункциональных требований (SLA, безопасность, аудит)
- Разработка стратегии обработки ошибок и матрицы рисков

## 🎯 Ключевые бизнес-цели

| Цель | KPI | Срок |
|------|-----|------|
| Выход в регионы | +50 городов доставки | 3 месяца |
| Снижение стоимости доставки | -25% к тарифу собственных курьеров | 6 месяцев |
| Прозрачность для покупателя | 95% заказов с онлайн-трекингом | День 1 после запуска |
| Автоматизация финансов | 100% электронный документооборот | День 1 после запуска |
